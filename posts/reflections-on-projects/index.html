Reflection on Projects

So, with the projects I feel I did learn significantly, especially metabase where i struggled a lot creating somthing meaningful and unique. In metabase, I tried to count the number of stations which collect data regarding these different kinds of pollutant; however I forgot that set of data was a recording collected by the station. I could have probably solved this by summarize query which would have grouped the duplicated into a singular entitiy. Making the chatbot was really fun honestly. My idea to not make a typical chat, make the whole expirience as if someone is going through a game before buying it. Well, the idea was far to ambitious, but still i ended up with somethin quite unique as well. Creating the initial page was the most difficult part of all. The custom CSS and understanding the typebot’s class selectors was really hectic. I mostly used the typebot’s documentation, stack overflow, DevTools for troubleshooting. Well, made me realize that learning new things require time and effort, and most of all patience.
